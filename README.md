# Pink Eyes

A parody of Shinigami Eyes: it colours some X/Twitter display names pink. The
pink doesn't mean anything — that's the joke.

For **Firefox** (desktop: macOS, Windows, or Linux), version 140 or newer.

---

## Install

Clicking the download link **downloads** the file instead of installing it —
that's normal, GitHub can't tell Firefox it's an add-on. It's two extra clicks:

1. **Download the add-on:**
   [pinkeyes-1.1.0.xpi](https://raw.githubusercontent.com/foxforfox/pinkeyes/refs/heads/main/pinkeyes-1.1.0.xpi)
   (right-click → Save Link As… if it opens instead of saving).

2. In Firefox, open **`about:addons`**
   (or menu ☰ → **Add-ons and themes**).

3. Click the **gear icon ⚙** near the top right → **Install Add-on From File…**

4. Pick the **`pinkeyes-1.1.0.xpi`** you just downloaded.

5. When Firefox asks, click **Add** to confirm.

That's it. On macOS the steps are identical — same `about:addons`, same gear
menu.

---

## After installing

- **It updates itself.** New versions arrive automatically within a few hours;
  you don't need to reinstall.
- **Turn it on for X/Twitter.** If names aren't colouring, open the add-on's
  options (☰ → Add-ons and themes → Pink Eyes → **Preferences**) and grant
  access to x.com when asked. That page also explains what to do if nothing's
  pink.

---

## Uninstall

`about:addons` → **Pink Eyes** → **Remove**.
